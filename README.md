# TimeLoopGame
Trapped in a Collapsing Lab
You’re a scientist caught in a 60-second time loop, forced to solve physics-defying puzzles while gravity shifts around you. Can you escape before time runs out… again?

Features:
🔑 Time-Loop Mechanic – Solve puzzles across multiple resets, learning from each loop
🔄 Gravity Manipulation – Flip the world to walk on ceilings and unlock hidden paths
🧩 Brain-Bending Puzzles – Crack codes, rewire circuits, and outsmart security systems
⏳ High-Stakes Urgency – The clock is always ticking (literally)
🚪 Final Escape – Uncover the lab’s secrets in a climactic ending

Perfect For Players Who Love:

Portal’s mind-bending physics

Outer Wilds’ time-loop exploration

Classic escape room challenges
